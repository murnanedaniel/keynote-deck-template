# Facts used in the scenes

Every number shown on a scene, with its exact value and citation. If someone in the audience asks where a number comes from, the answer is here. Replace these example entries with your talk's own.

## bigNumber

- 40 million bunch crossings per second at the LHC: 25 ns bunch spacing gives a 40 MHz nominal crossing rate. *CERN-2020-010 (HL-LHC Technical Design Report).*
- 1 million per second kept by the HL-LHC ATLAS first-level trigger (Level-0 output rate, 1 MHz). *ATLAS-TDR-029 (Phase-II TDAQ TDR).*

## chart: Higgs boson mass measurements (GeV, total uncertainty)

| measurement | value | source |

| ATLAS + CMS combined, Run 1 | 125.09 ± 0.24 | Phys. Rev. Lett. 114 (2015) 191803, doi:10.1103/PhysRevLett.114.191803 |
| CMS, Run 1 + 2016 | 125.38 ± 0.14 | Phys. Lett. B 805 (2020) 135425, doi:10.1016/j.physletb.2020.135425 |
| ATLAS, Run 1 + Run 2 | 125.11 ± 0.11 | Phys. Rev. Lett. 131 (2023) 251802, doi:10.1103/PhysRevLett.131.251802 |

Derived on the scene: "uncertainty halved" is 0.24 → 0.11 GeV (a factor 2.2); "one part in a thousand" is 0.11 / 125.11 ≈ 0.09%.
